== Experimental scalar MVP and next acceptance

The immediate experimental MVP is scoped by
link:../decisions/ATOMA-SCALAR-SOURCE.adoc[the closed scalar source decision].
Complete hosted evidence was obtained at
`3ea192650d752da1e4dbb504c7fa2a6568778aed` in
https://github.com/hyperpolymath/atoma/actions/runs/45491963944[run 45491963944]:
both real consumers, every byte input in four Zig build modes, source replay,
closed assumptions and all five scalar replay attacks. Subsequent gate
hardening requires both consumers exactly once, validates complete manifest
records and requires completed evidence from each. Every PR head must pass
the required checks before merge. The implemented path connects
the actual Proven word encoder and UAA protocol classifier to fresh Idris2
contracts and independently interprets their source bytes in Coq. It leaves
pointer/ownership and stateful foreign-boundary obligations explicit.

The scalar MVP merged in PR #30 at `c59fe78fceeaf284c0beab96300c9ad392150598`.
The next theory slice has checked universal decoder models in strict safe
Agda, full safe Cubical, Lean and Coq/coqchk; see
link:../theory/UNIVERSAL-DECODER.adoc[the statements, hosted evidence and limits].
PR #32 subsequently bound the actual decoder/import and registry-kernel source.
PR #33 added the original wrapper call/scan profiles and an explicit raw-alias
counterexample. Its complete hosted campaign passed at head
`6823ff07297ca015a2461c00adc2ee2215633d1a` in
https://github.com/hyperpolymath/atoma/actions/runs/45580361419[run 45580361419],
including fresh Proven/UAA native checks and independent ECHIDNA/Coq replay.
Cross-kernel correspondence and native pointer/lifetime premises remain open.

* Proven: qualify the actual public pointer-to-slice entry against bounded
  borrowed spans, null refusal and backend effects. Immediate tagged words are
  not allocated objects; pointer-carrier correspondence remains separate.
* UAA: qualify retained callback/context lifetimes, shared registrations,
  unregister and idle/busy destruction against the actual Zig declarations.
* The shared heap/permission protocol and both source-bound pilot extensions are
  implemented by PR #34; its exact head must pass the full required campaign.
  See link:../decisions/ATOMA-HEAP-BOUNDARY.adoc[acceptance and remaining premises].
* Second-language transfer spike before choosing the full sibling sequence.

General store/loop/permission refinement, native allocation authority, compiler
refinement and the complete required kernel chain remain open. A passing scoped
gate is not production readiness.

== Dogfooding status

The frame and u8 examples exercise the local verifier/tooling path. Proven and
UAA now supply real scalar helpers and fresh Idris2 oracle evidence in hosted
CI. No production deployment window or broad CRG qualification is established.
The four inherited Idris ABI quarantines remain documented and excluded from
claims about checked implementations. See link:PROOF-STATUS.adoc[proof status].
