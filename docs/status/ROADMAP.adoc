estimates. Atoma is experimental. There is no overall readiness percentage.

== Observed state

The repaired CLI and required soundness gate passed at
`f87b7408ab43d82c555ca8487878f4f5d6ec606b` in hosted run
https://github.com/hyperpolymath/atoma/actions/runs/42403751163[42403751163].
The source commands reject failed output delivery. Tests cover 24 tool cases,
13 frame cases, all 256 inputs of the compiled u8 pilot, executable Idris
extraction, four Agda modules and eight gate-falsifier groups.

Identity/ownership repair instantiates the original RSR template provenance,
removes its production claims, and names `atoma_chora.deed`. The PR's current
head must independently pass hosted checks before merge.

== Next acceptance

* Extend the locally passing finite-model replay slice to a checked
  source-to-model argument. Its ECHIDNA/coqchk path requires fresh source/proof
  identity and closed assumptions; it does not establish Zig refinement.
* Typed semantic boundary and explicit memory/alias counterexample.
* Second-language transfer spike before choosing the full sibling sequence.

Store, loops, permissions, compiler refinement and the complete required
kernel chain remain open. A passing scoped gate is not production readiness.

== Dogfooding status

The frame and u8 examples exercise the local verifier/tooling path. No external
consumer evidence window or broad CRG qualification has been established.
The four inherited Idris ABI quarantines remain documented and excluded from
claims about checked implementations. See link:PROOF-STATUS.adoc[proof status].
