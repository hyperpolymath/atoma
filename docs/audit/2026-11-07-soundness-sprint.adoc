== Review boundaries and remaining work

* No Zig-to-Agda refinement theorem, checked general VC generator, general
  alias/loop/call model or Dedukti/Coq/Lean4 replay was added.
* The u8 experiment is a deliberately tiny, exhaustively checkable language;
  its parser, lowering, emitter, evaluator and compiler remain trusted.
  Passing the general token screen still proves no semantic subset membership.
* The frame repair assumes a valid writable output lease disjoint from input,
  handle and iterator. It checks null pointers, not arbitrary pointer validity.
* This PR does not mint the inherited deed, edit licences, fix all template
  workflows, certify standards compliance or publish a release.
* CI bootstrap dependencies are not a fully reproducible Guix closure. The
  bounded deviation must be retired or reviewed before release.
* Sibling plans were compared for reuse opportunities; their engines were not
  audited or modified. See `../decisions/ATOMA-SIBLING-TRANSFER.adoc`.
