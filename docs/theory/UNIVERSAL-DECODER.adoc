= Universal decoder proof development

The target is acceptance exactly when a word is the canonical RefC Bits8
encoding of a byte. Testing all encoder inputs does not establish this:
the decoder must refuse every noncanonical 64-bit word.

== Theory stage

`CanonicalWord.agda` models every 64-bit pattern as 24 high bits, eight payload
bits, 31 padding bits and a tag. Its decoder requires zero high/padding bits
and a set tag. It proves soundness, completeness, encoder injectivity and
universal noncanonical rejection without enumerating words. The compatible
safe check runs first, followed by a full safe Cubical import check.

Lean and Coq independently prove the arithmetic statement over all natural
words: `decode w = Some b` iff `b < 256` and `w = b * 4294967296 + 1`.
Thus the arithmetic statement also covers all uint64 inputs. Coq's proof
assumptions are required to be closed; Lean's complete kernel-axiom report is
retained and any admitted theorem (`sorryAx`) fails. Standard Lean kernel
axioms, if reported by arithmetic tactics, are not hidden or described as an
axiom-free proof.

These are independently written models. Machine-checked correspondence
between Agda's bit fields and the arithmetic statements remains open; they
are not yet an exchanged cross-kernel proof witness or a derived proof grade.

== Source and consumer stage

Pending: extract Proven's raw-word decoder into a pure Zig helper, retain the
Idris2 ABI as authority, and bind the helper's source bytes to a closed
interpreter with guards and checked narrowing. Require rejection mutants for
missing bounds, missing canonical equality, altered shift/tag and unbound
imports. Retain native SDK/layout and actual-wrapper checks alongside proof.

Pointers here carry immediate tagged words, not allocations. Pointer
provenance, borrowed buffers, foreign calling conventions and compiler
refinement remain separate obligations. UAA's following state milestone must
frame refusal paths and endpoint updates, preserve callback/context identity,
and restore busy state on normal callback return under explicit ownership and
serialization assumptions. No termination or arbitrary foreign-memory safety
claim follows from these decoder theorems.

Hosted results are pending when this development stage is introduced. All
compiler and prover execution remains in remote CI during the local-work hold.
