= frame-v1 — the worked example

A length-prefixed, CRC-protected frame is validated in place and described by a
C-ABI `extern struct` pointing back into the caller's buffer (zero copy). This
directory is the executable part of `docs/spec/ATOMA-SPEC.adoc` §8.

== The four artefacts

[cols="2,3", options="header"]
|===
| Artefact | Path

| (a) Idris2 ABI and QTT contract
| `abi/FrameAbi.idr`, `abi/FrameAbi.ipkg`, `abi/Linearity.idr`
| (b) Zig implementation
| `src/frame_parse.zig`, `src/atoma.zig` (trusted runtime primitives)
| (c) Verification conditions
| `vc/gen_vcs.py` → `vc/*.smt2` (14 artefacts)
| (d) Failure analysis
| §8.4 of the spec, backed by the `*_mutant_*` and `*_needle_*` queries
| (e) Subset checker and extractor
| `tools/atoma` (this repo's CLI), exercised by `fixtures/violations.zig`
| (f) The soundness theorem
| `../../verification/atoma/agda/{Core,Soundness}.agda`
|===

Two contract faces, one IR:

[cols="2,3", options="header"]
|===
| File | Source

| `spec/face-a.cspec` | what `encode frameParse` prints (Idris2 is normative)
| `spec/face-b.cspec` | *extracted* from `src/frame_parse.zig` by `atoma extract`; do not hand-edit
| `spec/layout.cspec` | compiler-witnessed layout rows, 4 target classes
|===

== Run it

[source,bash]
----
./verify.sh            # gates G1..G11, writes witness/phase0.receipt.json
----

Gates, in order:

* *G1* 11 unit tests pass (Zig 0.15.2 and 0.16.0)
* *G2* compiles for x86_64, aarch64, riscv64, wasm32
* *G3* 60 layout rows confirmed by the compiler
* *G4* the `usize`-across-FFI fixture is rejected on wasm32
* *G5* Face A and Face B hash equal; a one-token edit diverges
* *G6* 11 mutation operators, 11 distinct artefacts
* *G7* 14 SMT obligations discharged by z3 (skipped, and recorded as `not-run`,
  when z3 is absent)
* *G8* `atoma extract` reproduces `spec/face-b.cspec` byte for byte
* *G9* the implementation is subset-clean: 6 exports, 6 contracts, 0 diagnostics
* *G10* `fixtures/violations.zig` is rejected: 20 diagnostics over 17 codes
* *G11* the Agda metatheory typechecks under `--safe --without-K` (skipped, and
  recorded as `not-run`, when agda is absent)

G7 and G11 are the two gates that depend on tools outside this repository. They
never *pass* by being absent; the receipt records `not-run` and the status stays
`INCOMPLETE (Warrant)` either way.

The receipt says `INCOMPLETE (Warrant)`. It is promoted to `COMPLETE (Receipt)`
only when the Dedukti witness has been rechecked by `coqchk` and
`lean4checker --fresh` — see §7.4 of the spec.

== Wire format

[cols="1,1,2", options="header"]
|===
| Offset | Size | Field

| 0 | 2 | magic: bytes `0x41 0x54` (`'A' 'T'`), i.e. little-endian u16 `0x5441`
| 2 | 2 | payload length, 0..65535
| 4 | 1 | flags; bit 0 = compressed, all other bits must be 0
| 5 | 1 | application tag
| 6 | 4 | IEEE CRC-32 over bytes 0..6 followed by the payload
| 10 | 2 | reserved, must be 0
| 12 | len | payload
|===

The magic is `0x5441`, not `0x4154`: the *bytes* are the contract, and `0x4154`
would put `'T'` first. `test "wire order"` pins this, and `V5_mutant_wrong_endian`
shows the solver refuting the plausible mistake.
