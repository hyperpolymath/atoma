= Atoma — experimental verification for Zig
:toc:

Atoma develops source-bound verification for an explicitly closed Zig subset.
It currently provides canonical contracts, a syntax screen, typechecked Idris2
specifications, Agda proofs of a store-free model and a finite u8 source pilot.
It is not yet a general sound verifier for Zig. Evidence remains
*INCOMPLETE (Warrant)*: compiler/refinement arguments and independent replay
are unfinished.

== Build and check

Use Zig 0.15.2, Z3 4.13.3 and the Agda/Idris2 profiles in
link:docs/decisions/ATOMA-TOOLCHAIN.adoc[the toolchain decision].
From the repository root:

[source,bash]
----
bash scripts/atoma-gate.sh
----

The gate rebuilds the current source, runs contract extraction and registered
proof checks, checks the good and wrong-body fixtures against every u8 input,
and exercises failures for missing tools, stale executables and I/O errors.
Evidence is written to `build/atoma-evidence/`. The hosted workflow publishes
the same evidence and is required on `main`.

== Current verification boundary

`tools/atoma` owns the command-line tooling and closed source pilot.
`examples/atoma/frame-v1` exercises the frame ABI contract and error paths.
`verification/atoma/agda` proves a model theorem; this is not a theorem about
the full Zig implementation. Legacy frame SMT queries remain model evidence.
The Idris QTT resource example is a model, not an executable foreign binding.

Read the link:docs/decisions/ATOMA-SOURCE-TO-PROOF.adoc[source-to-proof decision]
before extending claims or admitted language constructs. A solver answer or a
passing test must never be promoted to COMPLETE without the required checked
translation, provenance and kernel-replay evidence.
